Ship it

From folder to live site in four steps.

  1. Create a bucket

    Pick a globally unique name and the region closest to your audience.

  2. Enable static website hosting

    Set index.html as the index document in the bucket properties.

  3. Allow public read

    Turn off "Block public access" and attach a read-only bucket policy.

  4. Upload & visit

    Sync your files and open the bucket's website endpoint. Done.

bash — deploy 
# 1. Create the bucket
aws s3 mb s3://my-site-bucket

# 2. Enable static website hosting
aws s3 website s3://my-site-bucket \
  --index-document index.html

# 3. Upload your site
aws s3 sync . s3://my-site-bucket \
  --exclude ".git/*" --delete

✓ upload: ./index.html to s3://my-site-bucket/index.html
